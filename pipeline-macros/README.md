# pipeline-macros

Procedural macros (`#[pipeline]`, `#[stage]`) for the
[`pipeline`](https://github.com/dkumsh/pipeline) family.

**This is an internal implementation crate — don't depend on it directly.** Use
[`pipeline-dsl`](https://crates.io/crates/pipeline-dsl), which re-exports these
macros and is the supported entry point for the static DSL.
